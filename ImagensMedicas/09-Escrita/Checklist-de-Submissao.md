# Checklist de Submissao

## Conteudo

- [ ] Pergunta de pesquisa clara.
- [ ] Objetivos alinhados aos experimentos.
- [ ] Datasets descritos com numeros finais.
- [ ] Protocolo de split explicado.
- [ ] Modelos descritos de forma suficiente.
- [ ] Hiperparametros principais informados.
- [ ] Accuracy, CER e WER definidos.
- [ ] Tabela comparativa preenchida.
- [ ] Analise qualitativa incluida.
- [ ] Limitacoes declaradas.

## Reprodutibilidade

- [ ] Codigo referenciado.
- [ ] Seeds informadas.
- [ ] Ambiente descrito.
- [ ] Splits salvos.
- [ ] Checkpoints ou logs documentados.

## Forma

- [ ] Resumo dentro do limite.
- [ ] Figuras legiveis.
- [ ] Tabelas com unidades e legendas.
- [ ] Referencias completas.
- [ ] Revisao gramatical.
- [ ] Adequacao ao template do evento/revista.
